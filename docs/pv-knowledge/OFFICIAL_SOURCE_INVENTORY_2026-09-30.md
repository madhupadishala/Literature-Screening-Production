## Rules

- Only official regulator/harmonisation sources may enter the authoritative corpus.
- A landing page is not equivalent to an acquired/approved full-text source.
- Each acquired source must receive checksum, version/revision, publication/effective dates, lifecycle state and reviewer status.
- Superseded guidance remains retrievable only for explicit historical/date-scoped use.
- Draft/consultation material remains distinguishable from final/effective guidance.
- Regional implementation of ICH guidance must be tracked separately from ICH Step 4 adoption.

## Update-monitoring rule

Regulator-source monitoring is a standing platform obligation. A detected change must trigger:
- controlled source diff;
- applicability assessment;
- URS/FRS impact;
- code/test/SOP/User Guide impact;
- implementation deadline;
- validation evidence;
- activation of the new source version only after approval.
