# SOP Knowledge

SOPs are organised by PV business process. Every SOP receives its own document package.

## Process folders

- `Literature/` — literature search, screening, medical review, full-text/translation and literature-to-intake procedures.
- `ICSR/` — ICSR handling and case processing.
- `Triage/` — intake/triage and minimum criteria.
- `Aggregate/` — PSUR/PBRER and aggregate reporting procedures.
- `Signal/` — signal detection/evaluation procedures.
- `Submissions/` — safety submission procedures.
- `Quality/` — QA, deviation, CAPA, audit and training procedures.
- `Validation/` — CSV/computerised-system validation procedures.

Within a process folder:
- `Internal/` contains organisation-owned SOPs/WIs;
- `Reference/` contains externally supplied/reference SOPs;
- each version is retained separately;
- derived chunks/embeddings never replace the source.
