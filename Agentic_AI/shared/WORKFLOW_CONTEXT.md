# Shared Workflow Context Contract — all 27 agents

Nexus backend authenticates and authorizes the employee, selected tenant/client,
document and module **before** issuing a signed envelope. Agent workers verify
the envelope against their registered AG ID, use no mutable cross-job document
state, and persist/route outputs only using `bind_result`'s verified routing keys.
The agent must not infer its module from source content or accept tenant and client
IDs generated by an LLM. Each module may have its own queue and worker limits.

`workflow_context.py` supplies backend-side issue/verify/bind primitives.
`agent_context_registry.json` covers all 27 identities including four whose
agent implementations are currently missing. This contract does **not**
automatically wire the live queues, adapters, authorization service or workers.
`issued_at` expiry limits token age; durable queue retries need fresh
server-authorized issuance or a separately authenticated job claim. Enforce job
idempotency, replay protection and result write authorization in persistent
storage. Never expose signing keys to the frontend.
